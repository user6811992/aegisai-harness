Project Overview

AegisAi Harness is a feature-rich, local-only AI agent harness. OpenCode-class runtime, but offline-first: no cloud dependencies, no telemetry. 66 milestones, ~200 modules, 257 tests, CI green.

Successor to aegisai-next — that project is deprecated; all features have been ported here.

Architecture

The harness is an agent runtime: the model thinks, the harness decides what that thinking may touch.

Layers

  1. Backends (src/backends) — Ollama + OpenAI-compatible, streaming, routing, circuit breakers. 18 providers with auto-detection.
  2. Agent loop (src/agent/run.js) — tool calls, fallback models, budgets, gates (policy, charter, read-only, action guard, admission, MCP security), hooks, doom-loop detection, capsules, ledger capture.
  3. Tools (src/tools) — coding tools, registry, capability filtering, tool sets, discovery, output compression. 64+ tools.
  4. Integrations (src/integrations) — MCP client + security scanner, CDP browser (AX-first), REA/Ghidra/Craft.
  5. Memory & context — SQLite persistence, compaction + archive, source-bound/bi-temporal memory, context files, context filesystem, capsules.
  6. Quality — evals, benchmarks, harness score, reliability attribution, counterfactual optimizer, adversarial tests, CI template, conformance testing.
  7. Interfaces — CLI/REPL, --web UI, --rpc, OpenAI-compatible --proxy, JSON --json, --tui, --mcp-server.

Concepts & Patterns

  • Local-first — no cloud dependencies, no telemetry, all data stays local.
  • Zero dependencies — only optional better-sqlite3 and pdf-parse. Everything else is built-in.
  • Capability-based security — tools are filtered by allowedTools/deniedTools patterns per session.
  • Clean room mode — AI works only from observable behavior, no source code access.
  • Sandbox rings — 4-tier privilege system (ring 0 = most privileged).
  • Doom-loop detection — fingerprint-based detection of repeated tool calls with graduated response.
  • Composable stop conditions — stepCountIs, maxTokensUsed, maxCost, hasToolCall.
  • Context compaction — LLM-based + deterministic zero-LLM compaction with archive.
  • Bi-temporal memory — facts have validFrom/validTo timestamps for point-in-time queries.
  • Hebbian learning — edges strengthen with co-activation (hippocampus).
  • Evidence-based decisions — counterfactual analysis of failed vs successful runs.
