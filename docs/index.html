Features

🔒 Security First

Policy engine, governance charter, sandbox rings, clean room mode, doom-loop detection, PII redaction, encrypted vault, audit ledger.

🧠 Memory

Bi-temporal graph, hippocampus (Hebbian), source-bound memory, decision memory, RAG search, auto-extract, consolidation.

🔌 MCP Ecosystem

Client + server (stdio + HTTP), conformance, Apps, Tasks, .mcpb, interceptors, uploads, skills, registry browser.

🤖 Agent Orchestration

DAG, swarm, teams, multi-critic, task phases, async tools, cron, always-on layer, mailbox, delivery channels.

🔍 Reverse Engineering

REA, Ghidra, Craft, 30+ index, awesome-re 17k, pentest pipeline, vuln scanner, security KB, deep research.

📊 Observability

Run capture, harness score, reliability attribution, OTel export, SARIF, Merkle ledger, evidence bundles, conformance.

🖥️ Interfaces

CLI/REPL, web UI (Preact), TUI, RPC, OpenAI-compat proxy, JSON CLI, ACP/A2A adapters, native Windows desktop shell (Tauri v2).

🧩 Project Scaffolding

aegisai --init generates AGENTS.md, SOUL.md, TOOLS.md, MEMORY.md, PATH_RULES.md, MCP recommendations, and Aegis governance.

👥 Group Coordination

Broadcast/groups IPC in the desktop shell, parallel multi-agent orchestration, comprehension benchmarks.

📦 Packaging

Windows (Inno Setup + Tauri MSI/NSIS), macOS (DMG), Linux (AppImage), standalone binary, Docker, PWA.
